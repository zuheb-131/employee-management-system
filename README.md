# Employee Management System

A full-stack web application for managing employee records, built with FastAPI, PostgreSQL, and React.

---

## 🛠️ Tech Stack

* **Backend:** FastAPI (Python), PostgreSQL, SQLAlchemy, Pydantic
* **Frontend:** React, Vite, Tailwind CSS / CSS Modules
* **Tools:** Git, GitHub

---

## 🚀 Features

* Add, update, view, and delete employee details (CRUD operations).
* Fast and responsive REST API powered by FastAPI.
* Modern dynamic frontend interface built with React & Vite.
* Relational database integration using PostgreSQL.
